**Matriks Kompetensi Detail (Skill vs Level)** untuk:

1. Mechanical
2. Electrical
3. Instrumentation & Control (E&I)

Struktur level yang digunakan:

- **Level 1 – Junior**
- **Level 2 – Intermediate**
- **Level 3 – Senior / Technical Authority**

Skala kompetensi:

- 🔹 A = Awareness (paham konsep)
- 🔹 W = Working Knowledge (mampu melakukan dengan supervisi minimal)
- 🔹 I = Independent / Analytical (mandiri & mampu analisa)
- 🔹 E = Expert / Strategic (penentu keputusan & strategi)

# 📊 Cara Menggunakan Matriks Ini

1. Lakukan assessment awal setiap teknisi
2. Tandai posisi saat ini (A/W/I/E)
3. Tentukan gap terhadap level target
4. Buat Individual Development Plan (IDP)
5. Evaluasi tiap 6 bulan

---

# 📈 Contoh Target Upgrade

Misalnya:

Junior Mechanical → Target 2 Tahun:

- Alignment: W → I
- Seal installation: W → I
- RCFA: A → I
- API awareness: A → W

Jika 70% skill naik satu level → teknisi layak dipromosikan.
