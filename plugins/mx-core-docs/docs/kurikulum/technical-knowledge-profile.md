- Menghindari teori akademik berlebihan

- Mengembangkan diagram literacy
- Menghubungkan ke reliability & safety impact

## 6️⃣ SAFETY INTEGRATION RULE

Technical failure → System impact → Safety implication

- Loss of Containment risk
- Fire/explosion potential
- Equipment damage escalation
- Shutdown logic interaction

## 7️⃣ RELIABILITY CAUSE–EFFECT RULE

Operational trigger →
System consequence
